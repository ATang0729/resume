## Maintenance

- `index.html` and `index-en.html` are the complete master career records, not role-specific two-page resumes.
- Read [CUSTOMIZATION_GUIDE.md](CUSTOMIZATION_GUIDE.md) before adding experience or creating a tailored application version.

## Static site architecture

- `index.html` / `index-en.html`: semantic bilingual content.
- `style.css`: responsive screen theme, dark mode, mobile layout, and independent A4 print styles.
- `resume.js`: optional progressive enhancement for theme preference; the resume remains readable without JavaScript.
- No package installation or build step is required. Commit and push these static files to continue deploying through GitHub Pages.
